# Durability Alarm — Fabric 1.21.5

**Автор: Zadko. Версия 1.0.5.** Отдельный порт исходников для Minecraft 1.21.5. Настройки, локализации и иконка сохранены. После своей сборки замени предыдущий JAR; формат конфигурации не менялся.

Клиентский мод, предупреждающий о низкой прочности предметов. Это **исходники**, готового мода JAR в архиве нет.

## Что делает

- Проверяет основной инвентарь, панель быстрого доступа, экипировку, вторую руку и предмет на курсоре.
- Работает с инструментами, оружием, бронёй, элитрами, щитами, удочками и другими предметами с обычной прочностью Minecraft, включая предметы из модов.
- При остатке **10% или меньше** показывает оранжевое предупреждение, при **3% или меньше** — красное. Последняя единица прочности всегда считается критической.
- Показывает иконку, название, остаток вида `42 / 1561`, процент и расположение предмета.
- Подаёт локальный звуковой сигнал. Дополнительное сообщение в личный чат можно включить в настройках.
- Если повреждённых вещей много, переключает страницы каждые 5 секунд. Самая повреждённая вещь закреплена в первой строке при наличии хотя бы двух строк.
- Перекладывание одного и того же предмета между ячейками не вызывает новый сигнал. Для нескольких одинаковых вещей учитывается их количество.
- Если предмет продолжает изнашиваться, напоминает раз в 30 секунд. Для лежащих без дела вещей постоянных повторов нет. После починки пороги срабатывают снова.
- Проверяет инвентарь четыре раза в секунду, а не каждый кадр.

Мод показывает **остаток прочности**, а не точное время до поломки: оно зависит от действий игрока и зачарований. Он не останавливает действия и не предотвращает поломку автоматически.

## Сборка у себя

Нужен **JDK 21 или 25**. В архиве есть Gradle Wrapper, отдельно устанавливать Gradle не требуется. При первом запуске Gradle скачает зависимости — нужен интернет.

Распакуй архив. В папке `DurabilityAlarm-1.21.5-sources`, где лежит `build.gradle`, открой терминал.

Fedora / Linux:

```bash
java -version
javac -version
chmod +x gradlew
./gradlew build
```

Windows, PowerShell:

```powershell
java -version
javac -version
.\gradlew.bat build
```

`java` и `javac` должны быть версии 21 или новее. Подойдут JDK 21 и JDK 25; Java 17 не подходит. Компиляция нацелена на Java 21 независимо от выбранного JDK. При успешной сборке нужный файл:

```text
build/libs/durability-alarm-1.0.5+mc1.21.5.jar
```

Файл с окончанием `-sources.jar` в `mods` класть не нужно.

## Установка после своей сборки

1. В Prism Launcher открой сборку **Minecraft 1.21.5** с **Fabric Loader 0.19.5 или новее**.
2. Установи **Fabric API для 1.21.5**, версии `0.128.2+1.21.5` или новее для этой же версии Minecraft.
3. Положи собранный `durability-alarm-1.0.5+mc1.21.5.jar` в папку `mods` этой сборки.
4. Запусти игру. В мире нажми **K** → **Проверить предупреждение**. Пример появится на 8 секунд и ничего не изменит в инвентаре.

Мод устанавливается только на твой клиент; на сервер его ставить не нужно. Он использует данные инвентаря, которые уже известны клиенту. Сетевых запросов и собственных пакетов у него нет.

## Настройки

Клавиша **K** открывает настройки. Если она занята другим модом, переназначь её в обычном меню **Настройки → Управление → Назначение клавиш → Durability Alarm**.

В меню можно изменить проценты, включить или выключить звук и чат, выбрать угол панели, количество строк и период повторных напоминаний. Есть режим «только экипировка». Кнопка «Готово» или Escape сохраняет изменения.

Конфигурация лежит в `config/durability-alarm.json` внутри папки игры. Редактируй её при закрытой игре. Некорректные числа ограничиваются допустимыми пределами; повреждённый JSON по возможности сохраняется в отдельную копию перед восстановлением настроек.

В творческом режиме предупреждения по умолчанию выключены; их можно включить в настройках. В режиме наблюдателя они выключены всегда. F1 скрывает панель вместе с остальным интерфейсом. Панель также скрыта, пока открыт игровой экран, например инвентарь; звуковые предупреждения при этом могут работать.

## Границы поддержки

- Вложенные вещи внутри шалкеров, мешков и рюкзаков, вещи в сундуках и нестандартные слоты аксессуаров не проверяются.
- «Неразрушимые» предметы игнорируются.
- Нестандартная прочность, которую другой мод хранит вне стандартных компонентов Minecraft, требует отдельной интеграции.
- Название и зачарования входят в идентичность предмета: переименование или изменение зачарований может вызвать новое предупреждение.
- При сильных задержках сервера сведения о прочности могут приходить поздно. Мод не даёт гарантии сохранности вещей.

## Проверки и исходный код

Сборка Gradle и запуск Minecraft не выполнялись; готового JAR нет. Подробности переноса и выполненных проверок см. в `PORTING.md`. После своей сборки проверь меню по K, кнопку примера и предупреждения при износе предмета в отдельном мире.

`./gradlew logicTest` отдельно запускает проверки логики; `./gradlew build` также включает их в `check`.

Основные файлы:

- `DurabilityAlarmClient.java` — события клиента, клавиша, звук.
- `InventoryScanner.java` — чтение инвентаря и экипировки.
- `AlarmHud.java` — панель и краткое предупреждение.
- `AlarmSettingsScreen.java`, `AlarmConfig.java` — настройки и их сохранение.
- `core/DurabilityRules.java`, `core/AlertTracker.java` — пороги и защита от повторов.
- `src/test/java/.../AlarmLogicTest.java` — проверки поведения.

Проект использует официальные Mojang mappings для Minecraft 1.21.5. Loom remap подготавливает устанавливаемый JAR в пространстве имён intermediary; Yarn и mixin-инъекции не нужны. Настройки не требуют Mod Menu или YACL.

Источники для переноса и различия API перечислены в `PORTING.md`.

Код мода распространяется по MIT. Gradle Wrapper — сторонний инструмент проекта Gradle, под Apache License 2.0; см. `LICENSE-Gradle.txt`.

Иконка находится в `src/main/resources/assets/durability_alarm/icon.png` и подключена через поле `icon` в `fabric.mod.json`. Она отображается в совместимых списках модов, например в Mod Menu. Для самой работы мода Mod Menu не требуется.
